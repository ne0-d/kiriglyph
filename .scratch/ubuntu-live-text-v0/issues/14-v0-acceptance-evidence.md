# 14: Publish combined V0 acceptance evidence

**What to build:** Maintainers can decide what enters the installable alpha
using reproducible evidence from both exact Text selection and Subject Lift.

**Blocked by:** 10: Publish the Text milestone acceptance evidence; 13: Export
a selected subject as transparent PNG.

**Status:** blocked

- [ ] Shortcut-to-result walkthroughs cover text selection and transparent
  subject export from an image, website capture, and paused video frame.
- [ ] End-to-end latency and peak memory distinguish OCR, image embedding,
  prompt updates, mask rendering, clipboard, and PNG encoding.
- [ ] Repeated sessions prove bounded workers, models, memory, temporary files,
  clipboard data, and capture state.
- [ ] Privacy checks show no network inference, content telemetry, persistent
  pixels, recognized text, masks, embeddings, or notification previews.
- [ ] Manual Ubuntu 24.04 GNOME Wayland evidence covers cancellation, failure,
  multiple monitors, fractional scaling, keyboard use, and Orca.
- [ ] Known OCR and mask-quality limitations are documented with reproducible
  fixtures rather than hidden behind unsupported claims.
- [ ] The report recommends the alpha feature set, architecture, adapters,
  packaging work, and any capability that must remain experimental.
