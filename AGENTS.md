## Agent skills

Issues and specs are tracked as local Markdown under `.scratch/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Triage uses the default Matt Pocock skill labels. See `docs/agents/triage-labels.md`.

Domain documentation uses a single-context root glossary and ADR directory. See `docs/agents/domain.md`.

Tool paths, gotchas, the `scripts/check.sh` completion check, and fixture rules: `docs/agents/dev-commands.md`.
